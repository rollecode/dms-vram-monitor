# Third-party asset

## material-symbols-rounded.codepoints
Icon-name index for the Material Symbols Rounded font, used to populate the full
icon picker. DankMaterialShell ships the font (glyphs) but not this name index, and
its install path varies by version — so it's vendored here to keep the picker working.

- Source: https://github.com/google/material-design-icons (variablefont/MaterialSymbolsRounded[...].codepoints)
